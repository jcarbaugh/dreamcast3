Dreamcast3 Game Engine

Star Collector Game

Move your player to collect falling stars!

Score: 0
Controls: Arrow Keys (← →) or A/D to move | Click stars to collect bonus points!

Framework Features Demonstrated:

  • Native SVG rendering (no jQuery, no Flash)
  • Sprite animation with clip-path masking
  • Smooth movement with easing functions
  • Keyboard input handling
  • Click event handling on SVG elements
  • Scene management system
  • Game loop with delta timing
  • Collision detection
  • Native HTML5 Audio API integration
